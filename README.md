# ЭКО-культура media — прототип

Статичный прототип главной страницы. Файл `index.html` можно открыть в браузере или опубликовать через GitHub Pages.

## Что заменить перед публикацией

- В `index.html` заменить `media@example.com` и подпись «Укажите почту редакции» на адрес редакции.
- Добавить утверждённые обложки в `assets/covers/` и при желании заменить CSS-макеты обложек на изображения.
- Ссылки журналов сейчас ведут на заготовленные адреса `journals/edinomishlennik/` и `journals/ekotom/`; страницы выпусков добавляются следующим этапом.

## Публикация на GitHub Pages

1. Создать новый GitHub-репозиторий и загрузить содержимое этой папки в корень репозитория.
2. В репозитории открыть **Settings → Pages**.
3. В источнике публикации выбрать ветку `main` и папку `/ (root)`, затем сохранить.
4. GitHub Pages опубликует сайт по адресу репозитория.

Для прототипа Pages удобен как статичный хостинг. Перед запуском корпоративного портала следует проверить актуальные условия GitHub Pages и выбрать сервер/хостинг, подходящий для постоянной публикации компании.
